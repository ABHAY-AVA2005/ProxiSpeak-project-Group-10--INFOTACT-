# 03 - Evaluation, Review Rules and Stipend

## Review structure (team based)
Two reviews per monthly cycle, both for the entire team. Mid review has been **rescheduled to 27 to 30 October 2026**. The original brief says reviews happen only in given windows (20th to 27th for mid, 5th to 10th for final). Final review dates are not yet known.

| | Mid Review | Final Review |
|---|---|---|
| What is checked | Week 1 + Week 2 implementations | Week 3 + Week 4 implementations |
| GitHub requirement | In the 14 days before the review, each member shows individual progress on a minimum of 10 different days (development, documentation, testing, design, research or other assigned activity) | In the 20 days before the review, each member shows progress on a minimum of 20 different days |
| Commit rule | Commits can be by any team member; requirement is collective activity in the shared repo | The team needs at least one commit every single day in the 20-day period, no gaps |
| Fallback | If a member is unresponsive, the rest continue | The 20-day rule still applies |

## What the mid review assesses
- Completion of assigned Week 1 and Week 2 tasks
- Frontend implementation
- Backend/API development
- Database integration
- Functionality of implemented modules
- Individual contribution
- Understanding of the project architecture
- Technical explanation during the Mid Viva

## What the final review assesses
- Completion of all assigned project requirements
- Frontend and backend integration
- Database implementation
- API functionality
- Advanced features
- Code quality and project structure
- Individual contribution
- Deployment and working demonstration
- Technical understanding during the Final Viva

## Internship performance parameters
Attendance and punctuality; technical competency; quality of deliverables; innovation and problem-solving; communication and teamwork; adherence to timelines; documentation standards; final project review and presentation.

- Docs and code quality are 20%. Keep README, comments and write-ups current; do doc-focused work 2 days before each review.
